# Brand Builder

Describe a product and see it across many advertising mediums: a billboard, a newspaper ad, a social post, a vertical story, a magazine spread, a bus shelter poster, a store window, a website hero, and retail packaging. Every image is generated with **Nano-Banana** (`gemini-2.5-flash-image`).

## How it works

1. **Brief**: you enter a brand name, a product description, a tagline, brand colours and an art direction.
2. **Master product shot**: Nano-Banana designs one hero packshot of the product. You can also upload your own product photo instead.
3. **Mediums**: each medium you pick is generated by giving Nano-Banana that same master image plus a "product lock" prompt. The prompt says the product must be the identical object (same shape, colours, label and logo), and that only the scene, camera angle and lighting may change. This keeps the product consistent from shot to shot.
4. **No people**: every prompt includes a strict no-people rule. Each finished image is also checked by a Gemini vision model (`gemini-2.5-flash`). If it finds a person, hand, silhouette or mannequin, the image is regenerated, up to 3 attempts.

You can regenerate any single medium with a note (for example "make it night time"), design a new product, or download each image.

## Run it

```bash
npm install
cp .env.example .env   # then put your Google AI Studio key in GEMINI_API_KEY
npm start              # http://localhost:3000
```

| Env var | Default | Purpose |
| --- | --- | --- |
| `GEMINI_API_KEY` | — | Required. Get one at https://aistudio.google.com/apikey |
| `PORT` | `3000` | HTTP port |
| `PEOPLE_CHECK` | `1` | Set to `0` to skip the vision check (the prompts still forbid people) |
| `PEOPLE_CHECK_MODEL` | `gemini-2.5-flash` | Vision model used only for the people check |
| `MOCK` | `0` | Set to `1` to return placeholder images without calling the API, for UI work |

The image model is fixed to Nano-Banana in `lib/gemini.js` and cannot be changed through configuration.

## Project layout

```
server.js          Express API: /api/config, /api/reference, /api/medium
lib/prompts.js     Medium catalogue, product-lock and no-people prompts
lib/gemini.js      Nano-Banana calls, people-check retry loop, mock mode
public/            Frontend (plain HTML/CSS/JS)
test/              node:test unit tests (npm test)
```

Your API key stays on the server. The browser only talks to the local Express API.
